 # 👥 Sistema de Clientes

Sistema web para **cadastro e gerenciamento de clientes**, desenvolvido com HTML, CSS e JavaScript.

O projeto permite cadastrar, editar, excluir e pesquisar clientes, utilizando o **LocalStorage** do navegador para persistência dos dados.

## 🚀 Funcionalidades

* ✅ Cadastro de clientes
* ✏️ Edição de registros
* 🗑️ Exclusão de clientes
* 🔍 Pesquisa de clientes
* 📧 Validação de e-mail
* 📱 Validação de telefone
* 💾 Armazenamento utilizando LocalStorage
* 📊 Contador de clientes cadastrados

## ▶️ Como executar

### Opção 1 — Online

Acesse:

**[Sistema de Clientes](https://hugo191023.github.io/sistema-clientes/)**

### Opção 2 — No computador

Clone o repositório:

```bash
git clone https://github.com/hugo191023/sistema-clientes.git
```

Entre na pasta:

```bash
cd sistema-clientes
```

Depois abra o arquivo `index.html` no navegador.
